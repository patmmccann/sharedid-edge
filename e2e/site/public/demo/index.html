SharedID Edge, working live

SharedID Edge sets Prebid's SharedID as a server-set first-party cookie from the site's own CDN, so Safari doesn't cap it at 7 days. Each tile below is a real deployment that this repository's live tests deploy and test on every merge and every night. Open one: unmodified Prebid.js runs on that site, calls SharedID Edge on the same hostname, and a panel shows, with green checks, the cookie the server set in your browser, how long your browser will keep it, the ID Prebid.js puts into bid requests, and what the edge saw (your IP address and location, where those modules are on).

Each tile also shows the latest run of its live-test workflow on main: the deploy, the conformance suite, and the same browser tests in Chromium, Firefox and WebKit, against that deployment. How every deployment is tested: How SharedID Edge is verified.

Does Safari keep it for a year?

Safari caps cookies written by page script, and cookies set by a server on another IP address, at 7 days. Open any tile above in Safari: the panel's How long your browser keeps it check reads the cookie's expiry from Safari itself (the Cookie Store API, Safari 18.4 and later) and shows a year, not 7 days. In CI, the real-Safari tests (above) check the same cookies through safaridriver on a Mac, against a local server.
