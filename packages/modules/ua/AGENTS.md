# packages/modules/ua

User documentation is in [README.md](README.md) (also the npm package page); keep it in step with behaviour changes.

The `ua` module (`@sharedid-edge/module-ua`): User-Agent Client Hints and the `User-Agent` header as the `/v1` payload's OpenRTB 2.6 `ortb2.device` (`sua`, `devicetype`, `os`, `osv`, `make`, `model`, optional `ua`), and the shared traffic signal `device.ext.traffic` for self-identified bots. See the [spec section](../../../spec/SPEC.md#the-ua-module). It follows the module rules in [`../AGENTS.md`](../AGENTS.md).

- **Files:** `src/client-hints.ts` parses the hint headers (RFC 8941 lists, strings and booleans, GREASE); `src/module.ts` maps hints and the parsed `User-Agent` to `device` and applies consent; `src/parse.ts` has the parser interface and the built-in `botParser`; `src/bowser.ts` (the `./bowser` subpath export) has the optional full parser.
- **Runtime dependencies, an exception to the module rules:** [`isbot`](https://github.com/omrilotan/isbot) (Unlicense) is bundled into every adapter; [`bowser`](https://github.com/bowser-js/bowser) (MIT) only when a deployer imports `@sharedid-edge/module-ua/bowser`. Keep `bowser` out of `src/index.ts` and `src/module.ts`, or it lands in every bundle: the built-in module must stay within the Worker's and Lambda's 20 KB gzipped budgets. Any new dependency must be permissively licensed (MIT, BSD, Apache-2.0 or public domain), maintained, ESM, web-standard only, and typed under `skipLibCheck: false`; measure its gzipped cost with `npm run build -w @sharedid-edge/cloudflare`.
- **Request headers, not `PlatformInfo`:** the hints and `User-Agent` are sent by the browser, so the module reads them from `request.headers`. The one platform quirk handled here: `User-Agent: Amazon CloudFront` (CloudFront's substitute when the header isn't forwarded) counts as absent.
- **Hints first,** the parser second. Never send a value browsers freeze (macOS `10.15.7`, `Windows NT 10.0`, Android `10; K`, the `.0.0.0` in reduced Chromium versions).
- **Consent:** `highEntropyDenial` decides; the low-entropy and high-entropy field lists are in the spec, and moving a field between them is a spec change. The traffic signal is always sent (maintainer decision in #5).
- **The traffic signal** is the agreed shape from #5, `{ bot: true, botKind: 'declared', sources: ['ua'] }`, written through the normal deep merge. Switch to core's traffic-signal helper when it exists. Never write `bot: false`.
- **Settings fail loudly:** `uaSettings` throws on an unknown key or a non-boolean `ua`.
- Tests in `test/ua.test.ts` cover header parsing (GREASE, quoting, malformed values), the device-type mapping, a corpus of real User-Agents (`test/corpus.ts`), consent, the traffic signal and the module through `createHandler`. Conformance cases are in `conformance/cases/module-ua*.json`; they assert only what comes from hints and the bot flag, since other User-Agent parsing is implementation-defined.
